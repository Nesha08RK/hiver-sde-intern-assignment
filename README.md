# AI Customer Support Agent

AI-powered customer support agent developed for the Hiver SDE Intern take-home assignment.

## Project Status

🚧 In Development

## Objective

Build an AI support agent for one brand from the Customer Support on Twitter dataset that can:

1. Classify incoming customer messages into intents.
2. Draft replies grounded in historical support conversations.
3. Decide whether a message should be auto-handled or escalated to a human.

## Evaluation

The system will be evaluated using:

- A manually labelled golden evaluation set
- Simple baselines
- Automated classification metrics
- LLM-as-a-judge reply evaluation
- Human-vs-LLM judge agreement
- Failure analysis
